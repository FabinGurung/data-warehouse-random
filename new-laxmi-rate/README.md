# New Laxmi Store catalogue

The Google Sheet is authoritative for approved public catalogue fields: Item Name, EXIM Code, Description, Wholesale Value, Retail Value, Photo. No article IDs or database terminology is required. Blank codes, amounts and photos remain unknown. Existing example items and amounts are clearly marked SAMPLE. The earlier category/subcategory labels survive in descriptions; categories are not a published field.

Google Sheet: https://docs.google.com/spreadsheets/d/1zNf0DJ6-jC4j71XaL44XqF9ktgT82Sg9RjNQXVuUPwU/edit
Operating guide: https://docs.google.com/document/d/19lHTi-M9kv6qsim6lNhNM8T2irnWRtw0uoDeEKGJ4RY/edit

Review the private submissions and update Sheet/guide first. Then publish an approved snapshot using the manual CSV workflow or an authorized configured read-only integration. Do not expose the private submission document or credentials. Photo values are approved HTTPS URLs or existing local photos/ paths. Keep original private photos in Drive. Manual Actions publication may require a separate Pages deployment trigger and main reconciliation. No automatic private-Sheet access is implied.

The default Obsidian-inspired graph view derives expandable item and field nodes from the published six-column catalogue. The note explorer contains only public product data and a short public-safe explanation of the operating guide. Private intake is now a spreadsheet registered in that guide; never copy its link or raw submissions into Git. Table, gallery, CSV and print remain available.
